# Netflix Exploratory Data Analysis (EDA)

This project is part of my Data Science Internship at Auspify Technologies.

I used Python to explore the Netflix Movies and TV Shows dataset and understand the type of content available on the platform.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Work Done
- Loaded and explored the Netflix dataset.
- Checked the dataset structure and missing values.
- Compared Movies and TV Shows.
- Analyzed the top countries and genres.
- Explored release-year and content-added trends.
- Created graphs to understand the data.
- Summarized the main findings.

## Files
- `Netflix_EDA_Task2.ipynb` – Jupyter Notebook containing the analysis, code, graphs, and observations.
- `screenshots/` – Screenshots of the notebook outputs.

## Conclusion
This project helped me practice Exploratory Data Analysis using Python and understand how visualizations can be used to find patterns in a dataset.
